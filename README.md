# CanYouHelp.me prototype

A gentle, flower-themed suicide-prevention landing page prototype.

## Run locally
Open `index.html` in a browser. An internet connection is required for Tailwind Play CDN and Google Fonts.

## Important before public launch
- This prototype uses Tailwind Play CDN, which is for development/prototyping only. Use a compiled Tailwind build for production.
- The country picker links to an external directory; verify country URLs and directory behavior before launch.
- Review all copy with a qualified suicide-prevention professional or trusted adult.
- Obtain consent before publishing real stories and protect identifying details.
- This is not an emergency service and does not monitor visitors.
